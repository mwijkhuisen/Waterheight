# rws — Rijkswaterstaat monitoring map

A map of the Netherlands showing every measurement location that Rijkswaterstaat monitors, backed by
a thin API over the official Rijkswaterstaat WaterWebservices (WADAR / `ddapi20`).

Status: **Phase 1 (spike & sizing)** — see [`spike/README.md`](spike/README.md). The full brief is in
[`PROMPT.md`](PROMPT.md).
