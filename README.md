# Waterheight

**NL** — Rivierkijker is een publieke website (NL/EN) met een zelf gehoste OpenStreetMap-kaart van bijna-realtime waterstanden en afvoer, met waar beschikbaar officiële verwachtingen en waarschuwingen, van de rivieren die Nederland binnenstromen (NL, DE, BE, FR, LU, CH), met een datum- en tijdkiezer. Dit is een nieuwe start (fresh start): de legacy-code is gearchiveerd onder tag legacy-v0 (ADR-0001). Het plan staat in `docs/plan/`.

**EN** — Rivierkijker is a public website (NL/EN) with a self-hosted OpenStreetMap map of near-real-time river levels and discharge, with official forecasts and warnings where available, for the rivers flowing into the Netherlands (NL, DE, BE, FR, LU, CH), with a date/time selector. This is a fresh start: the legacy code is archived at tag legacy-v0 (ADR-0001). The plan lives in `docs/plan/`.
